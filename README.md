## 経験値の起算日（正式仕様）

- **各ユーザーの初回ログイン日（日本時間）を一度だけ保存**します。初めてログインする人はその日がXPの起算日になります。
- 既存利用者は2026-11-23を起算日としてSupabaseに設定しました。過去のOura／手動チェック履歴は削除せず、**起算日より前の実績はXPと週間ボーナスに含めません**。
- XPは起算日以降のチェック1件につき20、週目標達成ボーナス100。初回ログインが週の途中であれば、残り日数に合わせて週目標を調整します。
- `xpStartDate`をクラウドの習慣記録／JSONバックアップに保存。Supabaseの`hq_fix_xp_start_date`トリガーで、設定後に端末やインポートから変更・リセットできないよう保護しています。
- レベルは1〜50。進化形態は11段階、図鑑はLv.1〜50の全レベルを展開表示できます。Lv.50到達後はMAX表示です。

## スマートフォンの週間チェック

- Loop Habit Tracker・Habitifyの週間ビューを参考に、**共通7曜日ヘッダーと1習慣1行のグリッド**に変更しました。
- スマホでは**冒険・キャラクターのカードを先に表示**し、その下に週間トラッカーを置きます。手動習慣を紫で先に、Oura自動習慣を青緑で後に表示し、**Oura自動記録は折りたたまず常時表示**します。
- 画面幅が狭いときのみ週間グリッド部分を左右スクロールできます。日付と習慣が毎行縦方向に伸びる旧レイアウトは廃止しました。

## 習慣ごとの分析と設定（2026-11-23更新）

- 習慣名をタップすると個別分析に移動。直近1週間／1か月／3か月／6か月／1年（7/30/90/180/365日）の達成日数・対象日数・達成率・評価を確認できます。
- Ouraデータの未取得日は未達と区別し、Ouraの達成率は計測日数を分母にします。
- 今日の達成は**現在進行中の習慣**を分母にします（休止中は除外）。連続記録日数は**手動習慣を1つ以上実施した日**の連続回数、週間ミッションは**ミッションONの習慣の週目標回数の合計**です（Oura自動習慣は初期状態OFF、手動でONに変更可能）。集計範囲が異なるため、表示名で明示します。
- Oura連携・キャラクター画像管理は「⚙ 設定・連携・画像管理」内に配置します。
- 旧会話の抜粋と現在の実装を突き合わせた引き継ぎ事項は[HANDOFF.md](./HANDOFF.md)を参照。旧チャットの全文が取得できたわけではありません。
